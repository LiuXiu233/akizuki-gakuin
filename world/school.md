# 秋月学院 (Akizuki Gakuin)

## 一句话

一所位于海边小城秋月市、采用日式校园文化与管理方式的 **高等综合学院**——学生全部已经成年，
但校园里仍然有班级、制服、鞋柜、天台、社团、文化祭和放学后的商店街。

## 基本设定

| 项目 | 内容 |
|---|---|
| 全称 | 秋月学院高等综合学部 |
| 类型 | 成人高等学院 / 大学预科学院（三年制） |
| 学生年龄 | **全部 18 岁以上**（一年级 18–19，二年级 19–20，三年级 20–21） |
| 规模 | 约 720 名学生，每年级 8 个班 |
| 位置 | 秋月市北丘，从秋月站步行 12 分钟 |
| 创立 | 1948 年，前身是地方女子专修学校 |
| 校训 | 「自分の足で」——用自己的脚走 |
| 制服 | 深藏青西装制服，夏季白衬衫。领带/领结颜色按年级区分：一年级绿、二年级红、三年级蓝 |

## 为什么是"成人学院"却像高中

秋月学院面向已完成义务教育、准备升入大学或直接就业的成年人，
但学校刻意保留了传统日式校园的全部形式：晨会、值日、社团、学年活动、修学旅行。
理事会的官方说法是「集体生活的完成度决定个体的完成度」，
学生的说法是「因为这样比较有意思」。

结果就是：一群成年人穿着制服，认真地为文化祭的咖啡厅菜单吵三个小时。

## 学年节奏

- **4 月**：开学、社团招新、樱花。全年最容易认识新人的一个月。
- **5–6 月**：期中考、体育祭、梅雨。梅雨季是"共伞"事件的高发期。
- **7–8 月**：期末考、暑假、社团合宿、夏日祭、烟火大会、海边。关系推进最快的时期。
- **9–10 月**：文化祭准备期与文化祭。全校最忙、也最容易发生变化的三周。后夜祭是传统上的告白高峰。
- **11–12 月**：修学旅行、期末考、圣诞。
- **1–3 月**：初诣、情人节、白色情人节、学年末考试、毕业典礼。

## 校规（学生实际关心的部分）

1. 上课时间禁止外出，其余时间自由。
2. 社团活动 18:30 前必须结束，特别申请可延至 20:00。
3. 周三为全校社团休息日。
4. 天台"禁止进入"（锁坏了三年，没人修）。
5. 允许打工，需向班主任报备。
6. 学生已成年，恋爱不受校规限制；校方唯一的正式立场是「不要影响他人上课」。
7. 校内禁烟禁酒——**校外的成年学生不受此限，但学校不为此背书**。

## 校园传闻（rumor 级信息，未必为真）

- 旧校舍的暗房里有一卷从没冲洗出来的胶卷。
- 学生会长桐岛沙绘在入学考试拿了满分，但她从来不承认也不否认。
- 天台的锁不是坏了，是每年有人重新弄坏一次。
- 后夜祭结束时，在中庭那棵樱树下告白成功率会变高——统计学上完全没有依据。
- 三年级的水城连有一个没人见过的乐队。

## 世界观硬约束

- **不存在超自然力量。** 怪谈研究会收集的一切最终都有现实解释，或者永远不会有答案。
- **不存在"攻略路线"。** NPC 是成年人，有自己的生活、目标和感情对象。
- **世界不等待玩家。** 玩家不在场时，NPC 仍在上课、练习、吵架、和好、开始或结束一段关系。
