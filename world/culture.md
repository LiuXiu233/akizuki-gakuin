# 秋月的生活文化 (culture.md)

Agent 用这份文件把握"这个世界的人是怎么生活的"，从而写出有生活感的叙事。

## 一、日常语感

- 学生之间用名字或姓氏＋くん/ちゃん的中文对应处理：**熟悉度决定称呼**。
  - 陌生：全名 / 姓氏（"天野同学"）
  - 认识：姓氏（"天野"）
  - 熟：名字（"凛"）
  - 亲密：只有两个人在用的叫法（外号、缩短的名字）
  - **称呼的变化本身就是关系推进的信号**，比任何数值都直观。
- 对话里大量出现的东西：便利店、社团、作业、明天的考试、昨天的动画、谁和谁最近走得很近。
- 不要让所有人都用同一种语气词。每个角色的 `speech_style` 是硬约束。

## 二、放学后的经济学

学生一个月大约有 15,000–40,000 日元可支配。因此：

| 行为 | 大致花费 | 社交意义 |
|---|---|---|
| 自动售货机请一瓶饮料 | 110–160 | 最轻的示好，几乎没有压力 |
| 便利店一起买东西回家 | 300 上下 | 顺路，日常 |
| 家庭餐厅 | 800–1,500 | 可以坐很久，适合聊天和写作业 |
| 咖啡店 | 600–1,200 | 有点刻意，比家庭餐厅"更像约会" |
| 卡拉OK / 游戏厅 | 500–1,500 | 群体活动，也可以两个人去 |
| LIVE HOUSE | 2,000 | 共同兴趣的标志 |
| 海边 / 出游 | 3,000+ | 需要事先约定，是明确的邀请 |

**谁付钱**在这个世界里是有含义的：AA 是默认，主动请客是信号，被拒绝请客也是信号。

## 三、四季与情绪

- **春**：樱花、新班级、社团招新。所有关系的起点。空气里有一种"还什么都没决定"的感觉。
- **夏**：热、蝉、泳池、祭典、烟火、浴衣、海。距离感最容易被打破的季节。
- **秋**：文化祭、后夜祭、修学旅行。忙、亢奋、情绪外露。
- **冬**：暖气、围巾、圣诞、初诣、毕业。安静下来，也是回头看的时候。

## 四、恋爱在这个世界里的样子

**它不是一条进度条。**它长这样：

1. 你注意到她笔袋上换了挂件。
2. 她注意到你注意到了。
3. 某天放学，你们碰巧同一个方向，多走了两站路。
4. 她开始在你回消息之前先撤回一次。
5. 有人起哄，你们都笑了一下，然后各自转开视线。
6. 下雨那天只有一把伞。
7. 她提到了一件她没跟别人提过的事。
8. 你们都知道有什么变了，但谁都没说。
9. 然后其中一个人说了。或者没说，季节就过去了。

**这两种结局都是好故事。**

## 五、拒绝也是文化的一部分

- 拒绝通常是委婉的："那天可能有点难" / "下次吧"。
- 委婉不等于犹豫，也不等于"再努力一次就行"。
- 被拒绝之后关系不会归零，但会变。
- NPC 有权利在任何阶段说不，包括已经在交往之后。

## 六、群像感

这个世界的重点之一是：**其他人也在过自己的生活。**

- 黑泽和早乙女在为了完全不同的比赛训练。
- 白井和天野为了文化祭的选曲吵了两周。
- 冬月一个人在美术室待到关门。
- 有两个人已经在交往，只是没告诉任何人。

玩家可以走进这些故事，也可以完全不知道它们的存在。

## 七、成年人的部分

所有学生都是成年人，因此：

- 可以喝酒（校外）、可以打工、可以自己决定住哪里、可以谈成年人的恋爱。
- 对话里可以出现成人玩笑、两性话题、身体吸引的直白表达。
- 亲密关系是两个成年人自愿、明确同意、彼此尊重边界的结果。
- **但这些都需要过程。**没有任何检定、任何数值、任何"路线"能跳过过程。
